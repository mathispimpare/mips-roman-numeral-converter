# Roman Numeral Converter (MIPS)

A simple MIPS assembly program that converts an integer into a Roman numeral.

## Features

- Converts integers to Roman numerals
- Written entirely in MIPS assembly
- Supports values from 1 to 3999

## Requirements

- MARS MIPS Simulator
or
- QtSPIM

## How to Run

1. Open the `.asm` file in MARS or QtSPIM
2. Assemble the program
3. Run the program
4. Enter a number when prompted

## Example

Input:

```text
42
```

Output:

```text
XLII
```
